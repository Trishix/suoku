## 0.1.0a1 / 0.1.0-alpha.1 — unreleased

First open-source alpha candidate. The Python and npm version spellings refer to the
same release line; registry publication is not implied.

- Local archived-video retrieval with timestamped matches, content hashes, resumable
  ingestion, optional SigLIP embeddings, and explicit pinned model preparation.
- Optional BYOK visual insights through LiteLLM with configurable OpenAI, Anthropic,
  Gemini, Groq, and OpenRouter model identifiers.
- General, safety, warehouse, and bounded custom JSON Schema recipes; cached structured
  observations and answers with source citations and stated evidence limitations.
- Python, CLI, authenticated HTTP jobs, and typed TypeScript client workflows, including
  upload, analysis, questions, observations, status, and authenticated playback.
- Protected CLI configuration, separate API/worker processes, and explicit network
  opt-in for the container worker's cloud insights.
- Runnable examples, an attributed CC BY 3.0 animation sample, evaluation guidance,
  release checks, and security/contribution policies.

Semantic accuracy, safety-event performance, live provider compatibility, cloud cost,
and operational security require deployment-specific evaluation. No measured results or
production-readiness claims accompany this candidate.
